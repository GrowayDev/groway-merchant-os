**1. Executive Summary**

GroSell is Groway\'s proprietary WhatsApp commerce engine, embedded
natively within Merchant OS. It enables any Groway merchant --- across
all 12 verticals and 74 sub-verticals --- to sell directly through
WhatsApp conversations, powered by AI, and settled instantly via GoPay.

GroSell is not an integration with a third-party platform. It is a
Groway-owned product, built in-house, designed specifically for the
South African market and for the operational realities of every business
type on Merchant OS --- from a Shisa Nyama in Soweto to a full pharmacy
in Cape Town.

  -----------------------------------------------------------------------
  **GroSell\'s core competitive advantage is vertical-native
  intelligence. Where generic WhatsApp commerce platforms offer one
  universal chat flow, GroSell ships with 74 distinct, pre-configured
  conversational journeys --- one for every sub-vertical on Merchant OS.
  No competitor can match this depth.**

  -----------------------------------------------------------------------

**3.3 Native GoPay Checkout**

GroSell\'s checkout is powered entirely by GoPay and executes within the
WhatsApp thread --- no redirect to a browser, no third-party payment
page. This is GroSell\'s most significant technical advantage over
Flowcart.

-   GoPay payment link generated from within Merchant OS --- amount,
    reference, and merchant wallet pre-populated

-   Customer taps link inside WhatsApp and completes payment via card,
    EFT, PayShap, or QR

-   Payment confirmation webhook fires back to Merchant OS within 60
    seconds

-   Order auto-created in POS; stock deducted; KDS notified (for F&B)

-   Digital receipt sent in same WhatsApp thread including loyalty
    points earned

-   Cash-on-delivery and pay-in-store options available for merchants
    who prefer them

  -----------------------------------------------------------------------
  **Transaction fee: 0.8% per GroSell WhatsApp order --- lower than the
  1.0--1.5% on standard GoPay card transactions, as an incentive to drive
  WhatsApp channel adoption.**

**7. Technical Architecture**

**7.1 System Overview**

GroSell is built as a native microservice within the Merchant OS
architecture. It communicates with the WhatsApp Business API (Meta) and
integrates with existing Merchant OS modules via internal API calls ---
not external webhooks. This keeps latency low, data clean, and costs
minimal.

  -----------------------------------------------------------------------
  **Layer**              **Technology / Approach**
  ---------------------- ------------------------------------------------
  WhatsApp Connectivity  Meta WhatsApp Business API (Cloud API) ---
                         Groway holds BSP (Business Solution Provider)
                         status

  Conversation Engine    Groway-built state machine with AI overlay
                         (vertical-specific intent classifier)

  AI / NLP               Fine-tuned LLM trained on SA merchant data +
                         vertical catalogues, hosted on Groway
                         infrastructure

  Catalogue Sync         Real-time push from Merchant OS inventory ---
                         changes reflect in WhatsApp within 60 seconds

  Order Processing       WhatsApp orders create POS transactions via
                         internal Merchant OS order API (no external
                         webhook)

  Payment Layer          GoPay payment link API --- link generated
                         server-side, sent to customer in WhatsApp thread

  CRM Sync               Customer matched by phone number on first
                         interaction; new customers auto-created in MOS
                         CRM

  Offline Resilience     Message queue service holds outbound messages
                         during connectivity loss; retries on reconnect

  Database               New GroSell tables added to existing Merchant OS
                         PostgreSQL schema (Prisma ORM)

  Analytics              GroSell events streamed to Merchant OS reporting
                         module --- no separate analytics tool required
  -----------------------------------------------------------------------

**12. Conclusion**

GroSell represents one of the most strategically important product
investments Groway can make. WhatsApp is the dominant commerce channel
for South African consumers, and no existing platform is purpose-built
for the depth and diversity of businesses that Groway serves.

By building GroSell in-house, Groway owns the entire value chain ---
from the conversation to the checkout to the settlement to the credit.
No revenue leaks to third-party platforms. No dependency on a
competitor\'s roadmap. No one-size-fits-all flow that fails a Shisa
Nyama or a township pharmacy.
