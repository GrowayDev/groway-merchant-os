# Groway Merchant OS - Professional Services Vertical
## Comprehensive Feature Specification for South African Professional Associations

**Version:** 1.0
**Date:** April 2025
**Coverage:** South Africa statutory councils and professional bodies

---

## 1. Overview

The Professional Services Vertical provides comprehensive practice management for regulated professionals in South Africa, with deep integration into statutory councils, CPD management, and compliance tracking.

### Target Professions

| Council | Professions | Registered | Priority |
|---------|-------------|------------|----------|
| HPCSA | Health Professionals | ~450,000 | HIGH |
| ECSA | Engineers | ~45,000 | HIGH |
| SAICA | Chartered Accountants | ~50,000 | HIGH |
| LPC | Legal Practitioners | ~25,000 | HIGH |
| SANC | Nurses | ~280,000 | HIGH |
| SACNASP | Natural Scientists | ~15,000 | MEDIUM |
| SAPC | Pharmacists | ~15,000 | MEDIUM |
| AHPCSA | Allied Health | ~20,000 | MEDIUM |
| SACPCMP | Construction Professionals | ~10,000 | MEDIUM |
| SACSSP | Social Service Professionals | ~25,000 | MEDIUM |
| SACE | Educators | ~400,000 | MEDIUM |

**Total Addressable Market:** ~1.35 million registered professionals

## 5. Council Integration APIs

### 5.1 HPCSA Integration

```typescript
// Verify practitioner registration
GET /api/professional/hpcsa/verify/:practitionerNumber

// Check CPD status
GET /api/professional/hpcsa/cpd/:practitionerNumber

// Submit CPD activities
POST /api/professional/hpcsa/cpd/submit
```

### 5.2 ECSA Integration

```typescript
// Verify engineer registration
GET /api/professional/ecsa/verify/:registrationNumber

// Get CPD requirements
GET /api/professional/ecsa/cpd/requirements/:category

// Submit CPD record
POST /api/professional/ecsa/cpd/submit
```

### 5.3 SAICA Integration

```typescript
// Verify CA status
GET /api/professional/saica/verify/:membershipNumber

// Get CPD cycle status
GET /api/professional/saica/cpd/status/:membershipNumber

// Log CPD activity
POST /api/professional/saica/cpd/log
```

### 5.4 LPC Integration

```typescript
// Verify attorney registration
GET /api/professional/lpc/verify/:practitionerNumber

// Check fidelity fund status
GET /api/professional/lpc/fidelity-fund/:practiceNumber

// Submit trust return
POST /api/professional/lpc/trust-return
```

## 7. Database Schema (Prisma Models)

```prisma
model ProfessionalRegistration {
  id                    String   @id @default(cuid())
  staffId               String
  staff                 Staff    @relation(fields: [staffId], references: [id])
  council               String   // HPCSA, ECSA, SAICA, LPC, SANC, etc.
  registrationNumber    String   @unique
  category              String   // Registration category
  scopeOfPractice       String[] // Permitted activities
  registrationDate      DateTime
  expiryDate            DateTime
  status                String   @default("active")
  conditions            String?  // Limitations
  certificates          Certificate[]
  cpdRecords            CPDRecord[]
  renewals              Renewal[]
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}

model Certificate {
  id                    String   @id @default(cuid())
  registrationId        String
  registration          ProfessionalRegistration @relation(fields: [registrationId], references: [id])
  type                  String   // Registration, Good Standing, etc.
  certificateNumber     String?
  issueDate             DateTime
  expiryDate            DateTime?
  documentUrl           String?
  status                String   @default("valid")
  createdAt             DateTime @default(now())
}

model CPDRecord {
  id                    String   @id @default(cuid())
  registrationId        String
  registration          ProfessionalRegistration @relation(fields: [registrationId], references: [id])
  activityType          String   // Structured, Self-directed, Professional, Work-based
  title                 String
  description           String?
  provider              String?
  date                  DateTime
  duration              Float    // Hours or points
  points                Float?   // Points earned
  category              String?  // Ethics, Clinical, etc.
  certificateUrl        String?
  verified              Boolean  @default(false)
  notes                 String?
  createdAt             DateTime @default(now())
}

model Renewal {
  id                    String   @id @default(cuid())
  registrationId        String
  registration          ProfessionalRegistration @relation(fields: [registrationId], references: [id])
  renewalYear           String
  applicationDate       DateTime?
  paymentDate           DateTime?
  paymentAmount         Float?
  paymentReference      String?
  status                String   @default("pending") // pending, submitted, approved, rejected
  documents             String[]
  notes                 String?
  createdAt             DateTime @default(now())
}

model Practice {
  id                    String   @id @default(cuid())
  practiceNumber        String?  @unique
  name                  String
  tradingName           String?
  practiceType          String   // Solo, Partnership, Company
  registrationDate      DateTime?
  physicalAddress       String
  postalAddress         String?
  phone                 String
  email                 String
  website               String?
  bankName              String?
  bankAccountNumber     String?
  bankBranchCode        String?
  vatNumber             String?
  staff                 Staff[]
  clients               Client[]
  matters               Matter[]
  trustAccount          TrustAccount?
  compliance            PracticeCompliance?
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}

model Client {
  id                    String   @id @default(cuid())
  practiceId            String
  practice              Practice @relation(fields: [practiceId], references: [id])
  clientNumber          String   @unique
  firstName             String?
  lastName              String?
  companyName           String?
  contactPerson         String?
  email                 String?
  phone                 String?
  address               String?
  idNumber              String?  // For FICA
  registrationNumber    String?  // Company registration
  vatNumber             String?
  notes                 String?
  matters               Matter[]
  trustBalance          Float    @default(0)
  mattersOpen           Int      @default(0)
  mattersClosed         Int      @default(0)
  status                String   @default("active")
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}

model Matter {
  id                    String   @id @default(cuid())
  practiceId            String
  practice              Practice @relation(fields: [practiceId], references: [id])
  clientId              String
  client                Client   @relation(fields: [clientId], references: [id])
  matterNumber          String   @unique
  matterType            String
  description           String?
  responsibleAttorney   String?  // Staff ID
  status                String   @default("open")
  openedDate            DateTime @default(now())
  closedDate            DateTime?
  billableHours         Float    @default(0)
  feesBilled            Float    @default(0)
  feesPaid              Float    @default(0)
  tasks                 MatterTask[]
  documents             Document[]
  timeEntries           TimeEntry[]
  notes                 MatterNote[]
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}

model TrustAccount {
  id                    String   @id @default(cuid())
  practiceId            String   @unique
  practice              Practice @relation(fields: [practiceId], references: [id])
  accountName           String
  bankName              String
  accountNumber         String
  branchCode            String?
  balance               Float    @default(0)
  lastReconciliation    DateTime?
  transactions          TrustTransaction[]
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}

model TrustTransaction {
  id                    String   @id @default(cuid())
  trustAccountId        String
  trustAccount          TrustAccount @relation(fields: [trustAccountId], references: [id])
  clientId              String?
  matterId              String?
  type                  String   // Receipt, Payment, Transfer
  amount                Float
  reference             String?
  description           String?
  date                  DateTime @default(now())
  runningBalance        Float?
  createdAt             DateTime @default(now())
}

model PracticeCompliance {
  id                    String   @id @default(cuid())
  practiceId            String   @unique
  practice              Practice @relation(fields: [practiceId], references: [id])
  fidelityFundExpiry    DateTime?  // Legal
  fidelityFundNumber    String?
  healthCertExpiry      DateTime?
  fireCertExpiry        DateTime?
  responsiblePharmacist String?  // Pharmacy
  lastAudit             DateTime?
  nextAudit             DateTime?
  notes                 String?
  createdAt             DateTime @default(now())
  updatedAt             DateTime @updatedAt
}
```
