# Groway Merchant OS - Childcare & Education Vertical
## Comprehensive Feature Specification

**Version:** 1.0
**Date:** April 2025
**Target Markets:** South Africa

---

## 1. Overview

The Childcare & Education vertical provides comprehensive management for educational institutions, from early childhood development (ECD) centers to tertiary education providers.

### Target Segments

| Segment | Description | Size (SA) |
|---------|-------------|-----------|
| ECD Centers | Crèches, preschools, nurseries | ~25,000 |
| Primary Schools | Foundation and intermediate phase | ~15,000 |
| High Schools | Senior and FET phase | ~10,000 |
| Private Schools | Independent schools | ~2,000 |
| Tutoring Centers | Extra lessons, exam prep | ~5,000 |
| TVET Colleges | Technical vocational | ~50 |
| Universities | Higher education | 26 public + 100+ private |
| Special Needs Schools | Specialized education | ~500 |
| After-Care Centers | After-school care | ~8,000 |

## 12. API Endpoints Required

### Student Management APIs

```
GET    /api/education/students              # List students
POST   /api/education/students              # Create student
GET    /api/education/students/:id          # Get student
PUT    /api/education/students/:id          # Update student
DELETE /api/education/students/:id          # Archive student
GET    /api/education/students/:id/attendance # Attendance history
GET    /api/education/students/:id/grades   # Academic records
GET    /api/education/students/:id/fees     # Fee history
```

### Attendance APIs

```
POST   /api/education/attendance/mark       # Mark attendance
GET    /api/education/attendance/daily      # Daily report
GET    /api/education/attendance/monthly    # Monthly summary
POST   /api/education/attendance/biometric  # Biometric scan
```

### Fee Management APIs

```
POST   /api/education/fees/invoice          # Generate invoice
GET    /api/education/fees/statements/:id   # Fee statement
POST   /api/education/fees/payment          # Record payment
GET    /api/education/fees/arrears          # Arrears report
```

### Timetable APIs

```
GET    /api/education/timetable             # Class schedule
POST   /api/education/timetable             # Create schedule
GET    /api/education/timetable/teacher/:id # Teacher schedule
GET    /api/education/timetable/room/:id    # Room schedule
```

### Communication APIs

```
POST   /api/education/communicate/sms       # Send SMS
POST   /api/education/communicate/email     # Send email
POST   /api/education/communicate/whatsapp  # WhatsApp message
GET    /api/education/communicate/templates # Message templates
```

## 13. Database Schema (Prisma Models)

```prisma
model Student {
  id                String   @id @default(cuid())
  studentNumber     String   @unique
  firstName         String
  lastName          String
  dateOfBirth       DateTime
  gender            String
  idNumber          String?
  grade             String
  classId           String?
  class             Class?   @relation(fields: [classId], references: [id])
  parentId          String?
  parent            Parent?  @relation(fields: [parentId], references: [id])
  enrollments       Enrollment[]
  attendance        Attendance[]
  grades            Grade[]
  fees              FeeTransaction[]
  medicalInfo       MedicalInfo?
  documents         Document[]
  status            String   @default("active")
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
}

model Parent {
  id              String   @id @default(cuid())
  firstName       String
  lastName        String
  email           String?
  phone           String
  alternatePhone  String?
  address         String?
  students        Student[]
  payments        FeeTransaction[]
  communications  Communication[]
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}

model Class {
  id            String   @id @default(cuid())
  name          String
  grade         String
  teacherId     String?
  teacher       Teacher? @relation(fields: [teacherId], references: [id])
  students      Student[]
  timetable     TimetableEntry[]
  academicYear  String
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
}

model Teacher {
  id              String   @id @default(cuid())
  employeeNumber  String   @unique
  firstName       String
  lastName        String
  email           String
  phone           String
  saceNumber      String?
  qualifications  String[]
  subjects        String[]
  classes         Class[]
  timetable       TimetableEntry[]
  staff           Staff?   @relation(fields: [id], references: [id])
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}

model Attendance {
  id          String   @id @default(cuid())
  studentId   String
  student     Student  @relation(fields: [studentId], references: [id])
  date        DateTime
  status      String   // present, absent, late, excused
  checkIn     DateTime?
  checkOut    DateTime?
  notes       String?
  markedBy    String?
  createdAt   DateTime @default(now())
  
  @@unique([studentId, date])
}

model Grade {
  id            String   @id @default(cuid())
  studentId     String
  student       Student  @relation(fields: [studentId], references: [id])
  subject       String
  assessment    String
  mark          Float
  weight        Float
  term          String
  academicYear  String
  comments      String?
  gradedBy      String?
  createdAt     DateTime @default(now())
}

model FeeTransaction {
  id            String   @id @default(cuid())
  studentId     String
  student       Student  @relation(fields: [studentId], references: [id])
  parentId      String?
  parent        Parent?  @relation(fields: [parentId], references: [id])
  type          String   // invoice, payment, credit, debit
  amount        Float
  description   String
  dueDate       DateTime?
  paidDate      DateTime?
  method        String?  // cash, card,eft,debit_order
  reference     String?
  status        String   // pending, paid, overdue, cancelled
  createdAt     DateTime @default(now())
}

model TimetableEntry {
  id          String   @id @default(cuid())
  classId     String
  class       Class    @relation(fields: [classId], references: [id])
  teacherId   String?
  teacher     Teacher? @relation(fields: [teacherId], references: [id])
  subject     String
  day         String   // Monday-Friday
  period      Int
  startTime   String
  endTime     String
  room        String?
  createdAt   DateTime @default(now())
}

model MedicalInfo {
  id              String   @id @default(cuid())
  studentId       String   @unique
  student         Student  @relation(fields: [studentId], references: [id])
  allergies       String[]
  conditions      String[]
  medications     String[]
  doctorName      String?
  doctorPhone     String?
  emergencyContact String?
  emergencyPhone  String?
  notes           String?
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}
```
